# 🎬 MovieFinder

Aplicación web desarrollada con Laravel que permite a los usuarios explorar, buscar y gestionar información de películas, así como administrar su cuenta de forma segura.

---

## ✨ Características

- 🔐 Autenticación de usuarios (registro e inicio de sesión)
- 📧 Recuperación de contraseña vía correo electrónico
- 🔎 Búsqueda de películas
- 🛠️ Panel administrativo
- ⚡ Interfaz dinámica y responsive

---

## 🧰 Tecnologías

- **Backend:** Laravel 12 / PHP 8.4  
- **Frontend:** Blade / Bootstrap
- **Base de datos:** MySQL  
- **Herramientas:** Composer, Node.js, NPM  

---

## ⚙️ Instalación

```bash
git clone https://github.com/tu-usuario/tu-repo.git
cd tu-repo
composer install
npm install && npm run dev
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
